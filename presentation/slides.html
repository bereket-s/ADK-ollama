Foundation · Large Language Models

What is an LLM?

  • 📖
    Trained on text — Billions of words from books, code, web pages. The model learns patterns and relationships between words.
  • 🎲
    Predicts next tokens — Given a prompt, the LLM predicts the most likely next word, one token at a time, until a complete answer forms.
  • 🧠
    Emergent reasoning — With enough scale, models develop abilities: summarizing, coding, answering questions, following instructions.
  • ⚠️
    Limitation — LLMs alone can only generate text. They cannot browse the web, run code, or take actions in the real world.

Foundation · Google Agent Development Kit

What is Google ADK?

🏗️

A Framework for Agents

ADK (Agent Development Kit) is Google's open-source framework for building AI agents — systems where LLMs can plan, reason, and take actions.

🔧

Tools = Real Actions

ADK lets you connect the LLM to Python functions (tools). The model can call these tools to search, calculate, run code, or call APIs.

🔄

Agentic Loop

ADK implements Reason → Act → Observe cycles. The model thinks, calls a tool, sees the result, then thinks again until the task is done.

🤝

Multi-Agent

Multiple specialized agents can collaborate. An Orchestrator delegates subtasks to expert agents — like a team of AI specialists.

📡

Streaming

ADK supports real-time token streaming so users see the AI reasoning live — not just a final answer after a long wait.

🔓

Open Source

Free to use. Works with Gemini, GPT, Claude, and — as we'll show — local models via Ollama.

Agent Definition Pattern

AGENTS = {
  "research": {
    "name": "Research Agent",
    "model": "llama3.2",
    "system_prompt": """You are a Research Agent.
Use tools by outputting:
TOOL_CALL: {"tool": "name", "args": {}}
"""
  }
}

def parse_tool_calls(text):
    pattern = r'TOOL_CALL:\s*(\{[^}]+\})'
    for match in re.finditer(pattern, text):
        yield json.loads(match.group(1))

Code Walkthrough · app.py

Agentic Tool-Use Loop

async def agent_run(agent_id, user_message, history):
    messages = [system_prompt, *history, user_message]

    for round in range(MAX_TOOL_ROUNDS):   # max 5 rounds
        full_response = ""

        async for token in stream_ollama(model, messages):
            full_response += token
            yield sse("token", {"text": token})   # stream to browser

        tool_calls = parse_tool_calls(full_response)
        if not tool_calls:
            yield sse("done", {"message": full_response})
            break                                  # final answer ✓

        for call in tool_calls:
            result = execute_tool(call["tool"], call["args"])
            yield sse("tool_result", {"result": result})

        messages.append({"role":"user","content": result})  # feed back

End-to-End Flow

Request Lifecycle

  • 1
    User types message → Frontend sends POST /api/chat/{agent_id}
  • 2
    FastAPI builds message history + injects system prompt
  • 3
    Streams Ollama /api/chat — tokens arrive one-by-one
  • 4
    Agent outputs TOOL_CALL tag → Backend intercepts via regex
  • 5
    Real Python tool executes → result fed back to model as context
  • 6
    Loop repeats up to 5× → final answer streamed to browser
